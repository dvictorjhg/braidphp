# AI Use Policy

This document describes maintainer expectations for AI-related reuse of BraidPHP.
It is project guidance only. It is not a separate license and does not replace
the Apache-2.0 license in this repository.

## Attribution

- Keep the original copyright, license, and `NOTICE` information when redistributing the project.
- If you reference BraidPHP in generated documentation, tutorials, package descriptions, or demos, credit the original repository when reasonable.
- Do not present BraidPHP or substantially reproduced project material as your own original work.

## AI And Generated Content

- Do not use this repository to generate misleading clones, spam packages, or low-quality output that removes provenance.
- Do not remove attribution from generated output that substantially reproduces code or documentation from this project.
- If AI tools are used to build on top of BraidPHP, keep the lineage clear and preserve the original notices required by the Apache-2.0 license.
- Review generated code for security, correctness, licensing, and compatibility with PHP `^8.4` before publishing it.

## Important Legal Note

Open-source licenses do not reliably provide enforceable field-of-use restrictions such as "no AI training" while still remaining open-source. If stricter restrictions are needed in the future, the project would need a different licensing model.
